# Morse Defense

A Missile-Command-style game for learning Morse code. Asteroids fall toward your cities, each transmitting a character in Morse. Decode it and type the character to shoot it down.

**Play:** https://dsalfen.github.io/morse-defense/ (or just open `index.html` in any browser — no install, no dependencies)

## How it teaches
- **Koch method:** starts with K and M; a new character unlocks once every current one reaches 90% mastery.
- **Adaptive speed:** new or missed characters fall slowly; characters you know fall faster.
- **Full-speed sound:** characters always play at full speed (Farnsworth-style) — "slow" only means more time to answer.
- **Words:** 2-letter words appear once you know 10 characters, longer words at 20+.

## Controls
Type a character to fire · Space replays the signal · Backspace drops a word lock · Esc pauses

Progress is saved in your browser.
